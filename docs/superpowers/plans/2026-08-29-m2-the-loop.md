# M2 — The Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the run loop — classify, plan, review, reconcile, execute, validate, review, remediate, verify — for the `trivial` and `standard` tiers, on top of the M1 substrate.

**Architecture:** A state machine (`workflow/engine.py`) drives a run through stages. Each stage asks the context assembler for exactly the inputs its contract declares, resolves its role through the M1 registry to an adapter, and gets a Pydantic-validated structured result back. Nothing in `workflow/` knows provider command syntax; nothing in `adapters/` knows what a stage is. Two M1 controls that shipped without a production caller — the scope fence and the protected-config resolver — get wired here, which is the milestone's main safety deliverable.

**Tech Stack:** Python 3.14, Typer, Pydantic v2, pytest, ruff 0.16.4. No new runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-08-25-dev-orchestration-v1-design.md` (§5 divergences, §6 scope fence, §7 git safety, §8 M2, §10a context minimization, §14 final review). Stage input contracts come from `~/GitRepos/dev-orchestration-spec/WORKFLOWS.md` §2.

**Prior build record:** `.superpowers/sdd/2026-08-25-m1-foundation/` (gitignored) holds `progress.md`, the ledger of every M1 ruling, and `final-review.md`, the 791-line whole-branch review. Read the review's Important findings before Task 8 and Task 10 — several are closed by this plan and are called out by number where they are.

## Global Constraints

- **Encode invariants, not intelligence.** Anything true of any competently-run repository does not belong in a prompt, a template, or a context packet. This binds every task that produces agent-facing text.
- **Prompts are template files under `src/dev_orchestration/roles/`, never Python string literals.** (design §4)
- **Never push, merge, or deploy.** No code path — not a flag defaulting to off. `git/guards.py` fails closed.
- The string `--dangerously-bypass-approvals-and-sandbox` must never appear under `src/`.
- `codex exec` runs with `-s workspace-write` and `cwd` pinned to the run worktree.
- Branches follow `ai/<run-id>-<slug>`; worktrees live under `~/.dev-orchestration/worktrees/<repo>/<run-id>/`.
- **There is no `--allow-dirty` flag.** The clean-tree guard blocks non-trivial runs and names the files.
- **Validation receives no agent output at all.** It runs commands and records exit codes. A builder's claim that tests passed is not an input.
- **Superseded plan versions are never execution context.** They stay in the audit trail; only `approved-plan.md` is the contract.
- Structured output is enforced at the provider (`codex exec --output-schema`, `claude -p --output-format json`), validated against the same Pydantic models. **Schema failure triggers exactly one bounded retry, then escalates.**
- **Read-only roles may only bind to adapters declaring `read_only_review`.** M1's `build_request` raises `ReadOnlyRoleUnsupportedError` otherwise. Do not work around it.
- Deterministic path and category selection only. **No vector stores, embeddings, or retrieval scoring** — excluded until pilot evidence justifies them (§10a).
- Python 3.14, Pydantic v2, Typer, pytest. Use the repo venv: `.venv/bin/python -m pytest`, `.venv/bin/ruff`.
- `.venv/bin/ruff check .` and `.venv/bin/ruff format --check src tests` must pass. **Never run `ruff format .`** — it would reflow the historical plan and design documents under `docs/`.
- Baseline is **212 tests passing** on `main` at `48f30a8`.
- Tests must *constrain* the code, not merely execute it. Every task ends with a mutation check: change the behaviour, confirm a **named** test fails, restore.

### Machine traps that produce fake "mutation survived" results

Three of these bit the M1 build. All three are still present:

1. macOS BSD `sed` silently no-ops on the GNU-only `0,/regex/s//.../` address form. Prefer a Python edit, and always confirm the mutation actually landed before drawing a conclusion.
2. Python 3.14 `__pycache__` invalidation misbehaves here (the sandbox clock is set to 2026). `-B` only stops *writing* bytecode — stale `.pyc` files are still read. Clear `__pycache__` between runs.
3. A test parametrized over the very constant it mutates deletes its own case when that constant changes.

Additionally: `ruff format` may reflow code you are about to mutate. If a mutation target string is "not found", re-read the file before concluding anything.

# src/dev_orchestration/domain/findings.py
"""Structured results every review stage returns.

Finding IDs are stable across rounds: remediation references them and final
verification reports which remain unresolved, so an id that shifts between
rounds silently breaks that chain.
"""

import re
from enum import StrEnum
from typing import Literal, Self

from pydantic import BaseModel, model_validator

from dev_orchestration.domain.enums import Outcome, Tier

_FINDING_ID = re.compile(r"^F(\d{3,})$")

M2_TIERS = frozenset({Tier.TRIVIAL, Tier.STANDARD})


class Severity(StrEnum):
    BLOCKING = "blocking"
    IMPORTANT = "important"
    MINOR = "minor"


def next_finding_id(existing: list[str]) -> str:
    """Return the next sequential id, ignoring anything malformed.

    A provider returning a junk id must not reset the sequence, which would
    reuse an id that remediation is already tracking.
    """
    numbers = [int(m.group(1)) for i in existing if (m := _FINDING_ID.match(i))]
    return f"F{max(numbers, default=0) + 1:03d}"


class Finding(BaseModel):
    model_config = {"frozen": True}

    id: str
    severity: Severity
    summary: str
    evidence_required: str
    file: str | None = None
    line: int | None = None


class ReviewResult(BaseModel):
    model_config = {"frozen": True}

    outcome: Outcome
    findings: list[Finding] = []

    def blocking_ids(self) -> list[str]:
        return [f.id for f in self.findings if f.severity is Severity.BLOCKING]

    @model_validator(mode="after")
    def _pass_cannot_carry_blocking_findings(self) -> Self:
        if self.outcome is Outcome.PASS and self.blocking_ids():
            raise ValueError(
                f"outcome PASS contradicts blocking findings {self.blocking_ids()}"
            )
        return self


class Classification(BaseModel):
    model_config = {"frozen": True}

    tier: Tier
    rationale: str
    profiles: list[str] = []

    @model_validator(mode="after")
    def _tier_is_implemented(self) -> Self:
        if self.tier not in M2_TIERS:
            raise ValueError(
                f"tier {self.tier!r} has no implemented path in M2; "
                f"implemented tiers are {sorted(M2_TIERS)}"
            )
        return self


class AcceptanceVerdict(BaseModel):
    model_config = {"frozen": True}

    criterion: str
    verdict: Literal["PASS", "FAIL", "UNKNOWN"]
    evidence: str


class Verification(BaseModel):
    model_config = {"frozen": True}

    outcome: Outcome
    criteria: list[str] = []
    verdicts: list[AcceptanceVerdict] = []
    unresolved_finding_ids: list[str] = []

    @model_validator(mode="after")
    def _every_criterion_has_a_verdict(self) -> Self:
        judged = {v.criterion for v in self.verdicts}
        missing = [c for c in self.criteria if c not in judged]
        if missing:
            raise ValueError(f"no verdict for acceptance criteria: {missing}")
        return self
```

# src/dev_orchestration/schemas.py
"""JSON Schemas handed to providers, generated from the Pydantic models.

Generated rather than hand-written so the file the provider enforces and the
model we validate against cannot drift apart.
"""

import json
from pathlib import Path

from pydantic import BaseModel

from dev_orchestration.domain.findings import (
    Classification,
    ReviewResult,
    Verification,
)

SCHEMA_MODELS: dict[str, type[BaseModel]] = {
    "classification": Classification,
    "review_result": ReviewResult,
    "verification": Verification,
}


def schema_for(model: type[BaseModel]) -> dict:
    schema = model.model_json_schema()
    schema["additionalProperties"] = False
    return schema


def write_schema(model: type[BaseModel], directory: Path) -> Path:
    name = next(k for k, v in SCHEMA_MODELS.items() if v is model)
    directory.mkdir(parents=True, exist_ok=True)
    target = directory / f"{name}.json"
    target.write_text(json.dumps(schema_for(model), indent=2) + "\n", encoding="utf-8")
    return target
```

# src/dev_orchestration/context/packet.py
"""What a single stage is given, and nothing else.

Every item carries its provenance. Unlabelled concatenation is how a task
brief gets mistaken for a repository invariant, and how a reviewer's criteria
get mistaken for instructions to the builder.
"""

from pydantic import BaseModel


class ContextRef(BaseModel):
    model_config = {"frozen": True}

    label: str
    path: str | None
    content: str

    def render(self) -> str:
        source = f" ({self.path})" if self.path else ""
        return f"## {self.label}{source}\n\n{self.content.rstrip()}\n"


class ContextPacket(BaseModel):
    model_config = {"frozen": True}

    stage: str
    items: list[ContextRef] = []

    def render(self) -> str:
        return "\n".join(item.render() for item in self.items)

    def labels(self) -> list[str]:
        return [item.label for item in self.items]

    def total_bytes(self) -> int:
        return sum(len(item.content.encode("utf-8")) for item in self.items)
```

### Task 4: The context assembler and stage contracts

**Files:**
- Create: `src/dev_orchestration/context/assembler.py`
- Test: `tests/context/test_assembler.py`

**Interfaces:**
- Consumes: `ContextPacket`, `ContextRef` (Task 3); `ScopeFence` from `dev_orchestration.scope`.
- Produces: `Category` (StrEnum), `STAGE_CONTRACTS: dict[str, frozenset[Category]]`, `ContextContractError`, `assemble(stage: str, offered: list[ContextRef], fence: ScopeFence | None = None) -> ContextPacket`, `read_reference(repo_root: Path, rel_path: str, fence: ScopeFence) -> ContextRef`.

This is the heart of §10a. A stage declares which **categories** it may receive; the assembler refuses anything else. From `WORKFLOWS.md` §2:

> A role that receives another role's procedural instructions will try to perform that role. A builder given the reviewer's checklist starts reviewing.

The two consequences that must be executable, not advisory:

- **Validation receives no agent output at all** — its contract is `{COMMANDS, WORKTREE}`.
- **Superseded plan versions are never execution context** — execution receives `APPROVED_PLAN`, and there is no category for a superseded one.

The `label` on a `ContextRef` is its category. Offering a category the stage does not declare raises rather than silently dropping it: a silent drop makes a stage look correctly fed while it starves.

A role that receives another role's procedural instructions will try to

Isolation here is not tidiness, it is what keeps each stage doing its own job.

    APPROVED_PLAN = "approved_plan"

    BLOCKING_FINDINGS = "blocking_findings"

STAGE_CONTRACTS: dict[str, frozenset[Category]] = {
    "classification": frozenset({Category.REQUEST, Category.REPO_CLASS}),
    "planning": frozenset(
        {Category.BRIEF, Category.INVARIANTS, Category.REFERENCES}
    ),
    "plan_review": frozenset(
        {Category.BRIEF, Category.PROPOSED_PLAN, Category.PROFILE_CONSTRAINTS}
    ),
    "reconciliation": frozenset({Category.PROPOSED_PLAN, Category.REVIEW_FINDINGS}),
    "human_approval": frozenset({Category.APPROVAL_SUMMARY}),
    "execution": frozenset(
        {
            Category.APPROVED_PLAN,
            Category.INVARIANTS,
            Category.REFERENCES,
            Category.WORKTREE,
        }
    ),
    "validation": frozenset({Category.COMMANDS, Category.WORKTREE}),
    "implementation_review": frozenset(
        {
            Category.APPROVED_PLAN,
            Category.DIFF,
            Category.VALIDATION_EVIDENCE,
            Category.PROFILE_CONSTRAINTS,
        }
    ),
    "remediation": frozenset(
        {
            Category.BLOCKING_FINDINGS,
            Category.APPROVED_PLAN,
            Category.CURRENT_STATE,
        }
    ),
    "final_verification": frozenset(
        {
            Category.REQUEST,
            Category.APPROVED_PLAN,
            Category.ACCEPTANCE_CRITERIA,
            Category.CURRENT_STATE,
            Category.VALIDATION_EVIDENCE,
            Category.UNRESOLVED_FINDINGS,
        }
    ),
}


def assemble(
    stage: str,
    offered: list[ContextRef],
    fence: ScopeFence | None = None,
) -> ContextPacket:
    """Build the packet for `stage`, refusing anything its contract excludes.

    Refusal is loud. A silently dropped item makes a starved stage look
    correctly fed, which is far harder to diagnose than an exception.
    """
    allowed = STAGE_CONTRACTS.get(stage)
    if allowed is None:
        raise ContextContractError(
            f"unknown stage {stage!r}; declared stages are "
            f"{sorted(STAGE_CONTRACTS)}"
        )
    for item in offered:
        if item.label not in allowed:
            raise ContextContractError(
                f"stage {stage!r} may not receive category {item.label!r}; "
                f"its contract allows {sorted(allowed)}"
            )
    return ContextPacket(stage=stage, items=list(offered))


def read_reference(repo_root: Path, rel_path: str, fence: ScopeFence) -> ContextRef:
    """Read a repository file as a reference, refusing anything fenced out.

    This is enforcement point 1 of the scope fence (design section 6):
    excluded paths are never read and never reach an agent prompt.
    """
    if not fence.allows(rel_path):
        raise ContextContractError(
            f"{rel_path} is outside the scope fence and must not enter a prompt"
        )
    target = repo_root / rel_path
    return ContextRef(
        label=Category.REFERENCES,
        path=rel_path,
        content=target.read_text(encoding="utf-8"),
    )

# src/dev_orchestration/workflow/invoke.py
"""Call an adapter and validate its output against the expected model.

Schema failure gets exactly one bounded retry, then escalates. Not a loop: a
provider that cannot produce the shape twice will not produce it on the sixth
attempt either, and an unbounded retry burns budget silently.
"""

from dataclasses import replace

from pydantic import BaseModel, ValidationError

from dev_orchestration.adapters.base import AgentAdapter, AgentRequest


class SchemaEscalation(RuntimeError):
    """A provider failed to produce the required shape twice."""


def _validate(model: type[BaseModel], output: dict | str) -> BaseModel:
    if isinstance(output, str):
        return model.model_validate_json(output)
    return model.model_validate(output)


def invoke_structured(
    adapter: AgentAdapter,
    request: AgentRequest,
    model: type[BaseModel],
) -> BaseModel:
    result = adapter.run(request)
    try:
        return _validate(model, result.output)
    except (ValidationError, ValueError) as first_error:
        # The retry carries the validation error. A bare retry of an identical
        # prompt is a coin flip, not a correction.
        correction = (
            f"{request.prompt}\n\n"
            f"Your previous response did not satisfy the required "
            f"{model.__name__} schema:\n{first_error}\n"
            f"Return only valid {model.__name__} JSON."
        )
        retry = replace(request, prompt=correction)
        retry_result = adapter.run(retry)
        try:
            return _validate(model, retry_result.output)
        except (ValidationError, ValueError) as second_error:
            raise SchemaEscalation(
                f"{model.__name__} schema not satisfied after one retry: "
                f"{second_error}"
            ) from second_error
```

# src/dev_orchestration/workflow/engine.py
"""The run state machine.

Transitions are data, not scattered conditionals, so the legal shape of a run
is auditable in one place. Every transition persists the manifest AND appends
an event, so events.jsonl is a complete timeline rather than a sampling.
"""

from dev_orchestration.artifacts.store import RunStore
from dev_orchestration.domain.enums import RunState
from dev_orchestration.domain.run import RunManifest


class IllegalTransitionError(RuntimeError):
    """A transition the state machine does not permit was attempted."""


TERMINAL_STATES = frozenset(
    {
        RunState.COMPLETE_LOCAL,
        RunState.ESCALATED,
        RunState.FAILED,
        RunState.CANCELLED,
    }
)

# Escalation is reachable from every non-terminal state. A stage that cannot
# escalate has to invent a way out, and inventing a way out is the behaviour
# this whole framework exists to prevent.
_ALWAYS = frozenset({RunState.ESCALATED, RunState.FAILED, RunState.CANCELLED})

LEGAL_TRANSITIONS: dict[RunState, frozenset[RunState]] = {
    RunState.CREATED: _ALWAYS | {RunState.CLASSIFIED},
    # Trivial tier skips planning entirely and goes straight to execution.
    RunState.CLASSIFIED: _ALWAYS | {RunState.PLANNED, RunState.EXECUTING},
    RunState.PLANNED: _ALWAYS | {RunState.PLAN_REVIEWED},
    RunState.PLAN_REVIEWED: _ALWAYS | {RunState.PLAN_FINALIZED, RunState.PLANNED},
    RunState.PLAN_FINALIZED: _ALWAYS
    | {RunState.AWAITING_APPROVAL, RunState.EXECUTING},
    RunState.AWAITING_APPROVAL: _ALWAYS | {RunState.APPROVED},
    RunState.APPROVED: _ALWAYS | {RunState.EXECUTING},
    RunState.EXECUTING: _ALWAYS | {RunState.VALIDATING, RunState.BLOCKED},
    RunState.VALIDATING: _ALWAYS | {RunState.IMPLEMENTATION_REVIEW, RunState.BLOCKED},
    RunState.IMPLEMENTATION_REVIEW: _ALWAYS
    | {RunState.REMEDIATION, RunState.FINAL_VERIFICATION},
    RunState.REMEDIATION: _ALWAYS | {RunState.VALIDATING},
    RunState.FINAL_VERIFICATION: _ALWAYS | {RunState.COMPLETE_LOCAL},
    RunState.BLOCKED: _ALWAYS | {RunState.REMEDIATION},
    RunState.COMPLETE_LOCAL: frozenset(),
    RunState.ESCALATED: frozenset(),
    RunState.FAILED: frozenset(),
    RunState.CANCELLED: frozenset(),
}


class Engine:
    def __init__(self, store: RunStore) -> None:
        self.store = store

    @property
    def state(self) -> RunState:
        return self.store.read_manifest().status

    def transition(self, to: RunState) -> RunManifest:
        current = self.state
        if to not in LEGAL_TRANSITIONS.get(current, frozenset()):
            raise IllegalTransitionError(
                f"{current} -> {to} is not a legal transition; "
                f"legal targets are {sorted(LEGAL_TRANSITIONS.get(current, []))}"
            )
        manifest = self.store.update_manifest(status=to)
        self.store.append_event(
            {"event": "state_changed", "from": str(current), "to": str(to)}
        )
        return manifest
```

"""Everything that must be true before a single agent is invoked.

This is where the protected-config resolver acquires a production caller. It
was fully tested and entirely unwired through M1, which is the most dangerous
shape a control can take: a green test suite proving nothing about the running
system.
"""

from pathlib import Path

from dev_orchestration.artifacts.store import RunStore, new_run_id, slugify
from dev_orchestration.config.models import ProjectConfig
from dev_orchestration.config.resolver import PROTECTED_DEFAULTS, resolve_policy
from dev_orchestration.domain.enums import Tier
from dev_orchestration.domain.run import GitBlock, RunManifest
from dev_orchestration.git.repo import GitRepo
from dev_orchestration.git.worktree import create_worktree


class ProtectedRuleViolation(RuntimeError):
    """A protected rule resolved to something other than False."""


def resolve_run_policy(layers: list[dict]) -> dict:
    """Resolve configuration layers for a run.

    Thin by design: the precedence logic lives in config.resolver and is
    tested there. What this adds is a call site, which is what was missing.
    """
    return resolve_policy(layers)


def bootstrap_run(
    repo: GitRepo,
    project_config: ProjectConfig,
    request_text: str,
    tier: Tier,
    worktree_root: Path,
) -> tuple[RunStore, Path]:
    # No --allow-dirty flag exists, deliberately: bypassing this would branch
    # from HEAD and silently exclude the user's in-progress work.
    if tier is not Tier.TRIVIAL:
        repo.ensure_clean()

    policy = resolve_run_policy(
        [
            project_config.model_dump(mode="json"),
        ]
    )
    for key in PROTECTED_DEFAULTS:
        if policy.get(key) is not False:
            raise ProtectedRuleViolation(
                f"{key} resolved to {policy.get(key)!r}; protected rules are "
                "not overridable and a run must not start"
            )

    slug = slugify(request_text)[:40] or "run"
    run_id = new_run_id(str(tier), slug)
    branch = f"ai/{run_id}-{slug}"
    worktree = worktree_root / project_config.project.name / run_id

    store = RunStore(repo.root, run_id)
    store.initialize(
        RunManifest(
            run_id=run_id,
            repository=str(repo.root),
            workflow=str(tier),
            tier=tier,
            project_class=project_config.project.project_class,
            resolved_config=policy,
            git=GitBlock(base_commit=repo.current_commit(), branch=branch),
        )
    )
    create_worktree(repo, worktree, branch)
    store.update_manifest(git=GitBlock(
        base_commit=repo.current_commit(),
        branch=branch,
        worktree=str(worktree),
    ))
    store.append_event({"event": "run_bootstrapped", "run_id": run_id, "branch": branch})
    return store, worktree
```

# src/dev_orchestration/workflow/validation.py
"""Run the configured validation commands and record what happened.

This stage receives no agent output at all -- not the builder's report, not
the plan. Its independence from the builder's claim is the entire point, and
it is enforced structurally: there is no parameter through which a claim could
arrive.

Commands are screened against the non-overridable deny-list at config load, so
nothing denied can reach this function.
"""

import subprocess
from pathlib import Path

from pydantic import BaseModel

from dev_orchestration.config.models import ValidationCommand
from dev_orchestration.domain.enums import Tier

TAIL_CHARS = 4000


class ValidationOutcome(BaseModel):
    model_config = {"frozen": True}

    name: str
    command: str
    exit_code: int | None
    passed: bool
    stdout_tail: str
    stderr_tail: str


def run_validations(
    commands: dict[str, ValidationCommand],
    tier: Tier,
    cwd: Path,
) -> list[ValidationOutcome]:
    outcomes: list[ValidationOutcome] = []
    for name, spec in commands.items():
        if tier not in spec.required_for:
            continue
        try:
            # A validation command is a shell string from configuration
            # ("npm run build"), so it needs a shell. Passing it as an argv
            # list to /bin/sh -c keeps shell=True out of the codebase, which
            # tests/git/test_guards.py forbids with no exemptions.
            proc = subprocess.run(
                ["/bin/sh", "-c", spec.command],
                capture_output=True,
                text=True,
                cwd=cwd,
                timeout=spec.timeout_seconds,
                check=False,
            )
        except subprocess.TimeoutExpired:
            outcomes.append(
                ValidationOutcome(
                    name=name,
                    command=spec.command,
                    exit_code=None,
                    passed=False,
                    stdout_tail="",
                    stderr_tail=f"timed out after {spec.timeout_seconds}s",
                )
            )
            continue
        outcomes.append(
            ValidationOutcome(
                name=name,
                command=spec.command,
                exit_code=proc.returncode,
                passed=proc.returncode == 0,
                stdout_tail=proc.stdout[-TAIL_CHARS:],
                stderr_tail=proc.stderr[-TAIL_CHARS:],
            )
        )
    return outcomes


def all_passed(outcomes: list[ValidationOutcome]) -> bool:
    return all(o.passed for o in outcomes)
```

Note the `/bin/sh -c` form is deliberate and load-bearing: M1's `test_shell_equals_true_appears_nowhere` scans every module under `src/` for `shell=True` and grants **no exemptions**, so this is the only way to run a configured shell string.

def plan(
    registry: RoleRegistry,
    brief: str,
    invariants: list[ContextRef],
    references: list[ContextRef],
    store: RunStore,
) -> Path:
    packet = assemble(
        "planning",
        [ContextRef(label=Category.BRIEF, path=None, content=brief), *invariants, *references],
    )
    request = registry.build_request(
        "planner", prompt=load_role_prompt("planner"), cwd=store.repo_root, context=packet
    )
    result = registry.adapter_for("planner").run(request)
    text = result.output if isinstance(result.output, str) else json.dumps(result.output)
    path = store.write_plan_version(text)
    store.append_event({"event": "plan_written", "version": path.name})
    return path


def review_plan(
    registry: RoleRegistry,
    brief: str,
    plan_text: str,
    profile_constraints: list[ContextRef],
    store: RunStore,
) -> ReviewResult:
    packet = assemble(
        "plan_review",
        [
            ContextRef(label=Category.BRIEF, path=None, content=brief),
            ContextRef(label=Category.PROPOSED_PLAN, path=None, content=plan_text),
            *profile_constraints,
        ],
    )
    request = registry.build_request(
        "plan_reviewer",
        prompt=load_role_prompt("plan_reviewer"),
        cwd=store.repo_root,
        context=packet,
    )
    raw = invoke_structured(
        registry.adapter_for("plan_reviewer"), request, ReviewResult
    )
    result = _renumber(raw, store)
    store.append_event(
        {
            "event": "plan_reviewed",
            "outcome": str(result.outcome),
            "finding_ids": [f.id for f in result.findings],
        }
    )
    return result


def _renumber(result: ReviewResult, store: RunStore) -> ReviewResult:
    """Assign our own stable ids, ignoring whatever the provider returned.

    Remediation and final verification both reference these ids. A provider
    that reuses or invents one would silently break that chain, so provider
    ids are never trusted.
    """
    existing = _known_finding_ids(store)
    renumbered = []
    for finding in result.findings:
        new_id = next_finding_id(existing)
        existing.append(new_id)
        renumbered.append(finding.model_copy(update={"id": new_id}))
    return result.model_copy(update={"findings": renumbered})


def _known_finding_ids(store: RunStore) -> list[str]:
    path = store.root / "events.jsonl"
    if not path.is_file():
        return []
    ids: list[str] = []
    for line in path.read_text(encoding="utf-8").splitlines():
        ids.extend(json.loads(line).get("finding_ids", []))
    return ids


def reconcile(
    registry: RoleRegistry,
    plan_text: str,
    findings: list[Finding],
    store: RunStore,
) -> Path:
    packet = assemble(
        "reconciliation",
        [
            ContextRef(label=Category.PROPOSED_PLAN, path=None, content=plan_text),
            ContextRef(
                label=Category.REVIEW_FINDINGS,
                path=None,
                content="\n".join(f"{f.id} [{f.severity}] {f.summary}" for f in findings),
            ),
        ],
    )
    request = registry.build_request(
        "plan_reconciler",
        prompt=load_role_prompt("plan_reconciler"),
        cwd=store.repo_root,
        context=packet,
    )
    result = registry.adapter_for("plan_reconciler").run(request)
    text = result.output if isinstance(result.output, str) else json.dumps(result.output)
    path = store.write_plan_version(text)
    store.append_event({"event": "plan_reconciled", "version": path.name})
    return path

def execute(
    registry: RoleRegistry,
    approved_plan: str,
    invariants: list[ContextRef],
    references: list[ContextRef],
    worktree: Path,
    store: RunStore,
) -> AgentResult:

        "execution",
        [

            *invariants,

        ],
    )
    request = registry.build_request(
        "implementation_worker",
        prompt=load_role_prompt("implementation_worker"),
        cwd=worktree,
        context=packet,
    )
    result = registry.adapter_for("implementation_worker").run(request)
    store.append_event({"event": "executed", "exit_code": result.exit_code})
    return result

MAX_REMEDIATION_CYCLES = 2


class RemediationExhausted(RuntimeError):
    """Blocking findings survived the remediation budget."""


def review_implementation(
    registry: RoleRegistry,
    approved_plan: str,
    diff: str,
    validation_evidence: str,
    profile_constraints: list[ContextRef],
    store: RunStore,
) -> ReviewResult:
    packet = assemble(
        "implementation_review",
        [
            ContextRef(label=Category.APPROVED_PLAN, path=None, content=approved_plan),
            ContextRef(label=Category.DIFF, path=None, content=diff),
            ContextRef(
                label=Category.VALIDATION_EVIDENCE, path=None, content=validation_evidence
            ),
            *profile_constraints,
        ],
    )
    request = registry.build_request(
        "implementation_reviewer",
        prompt=load_role_prompt("implementation_reviewer"),
        cwd=store.repo_root,
        context=packet,
    )
    raw = invoke_structured(
        registry.adapter_for("implementation_reviewer"), request, ReviewResult
    )
    result = _renumber(raw, store)
    store.append_event(
        {
            "event": "implementation_reviewed",
            "outcome": str(result.outcome),
            "finding_ids": [f.id for f in result.findings],
        }
    )
    return result


def remediate(
    registry: RoleRegistry,
    blocking: list[Finding],
    approved_plan: str,
    current_state: str,
    worktree: Path,
    store: RunStore,
    cycle: int = 1,
) -> AgentResult:
    """Fix blocking findings, with a hard budget.

    The budget exists because a third attempt at the same finding is evidence
    the loop cannot close it, and burning turns is worse than telling a human.
    """
    if cycle > MAX_REMEDIATION_CYCLES:
        ids = [f.id for f in blocking]
        store.append_event({"event": "remediation_exhausted", "finding_ids": ids})
        raise RemediationExhausted(
            f"blocking findings {ids} survived {MAX_REMEDIATION_CYCLES} "
            "remediation cycles; escalating to a human"
        )
    packet = assemble(
        "remediation",
        [
            ContextRef(
                label=Category.BLOCKING_FINDINGS,
                path=None,
                content="\n".join(
                    f"{f.id}: {f.summary}\n  required evidence: {f.evidence_required}"
                    for f in blocking
                ),
            ),
            ContextRef(label=Category.APPROVED_PLAN, path=None, content=approved_plan),
            ContextRef(label=Category.CURRENT_STATE, path=None, content=current_state),
        ],
    )
    request = registry.build_request(
        "implementation_worker",
        prompt=load_role_prompt("implementation_worker"),
        cwd=worktree,
        context=packet,
    )
    result = registry.adapter_for("implementation_worker").run(request)
    store.append_event(
        {
            "event": "remediated",
            "cycle": cycle,
            "finding_ids": [f.id for f in blocking],
        }
    )
    return result
```

def verify(
    registry: RoleRegistry,
    request_text: str,
    approved_plan: str,
    criteria: list[str],
    current_state: str,
    validation_evidence: str,
    unresolved: list[str],
    store: RunStore,
) -> Verification:
    packet = assemble(
        "final_verification",
        [
            ContextRef(label=Category.REQUEST, path=None, content=request_text),
            ContextRef(label=Category.APPROVED_PLAN, path=None, content=approved_plan),
            ContextRef(
                label=Category.ACCEPTANCE_CRITERIA, path=None, content="\n".join(criteria)
            ),
            ContextRef(label=Category.CURRENT_STATE, path=None, content=current_state),
            ContextRef(
                label=Category.VALIDATION_EVIDENCE, path=None, content=validation_evidence
            ),
            ContextRef(
                label=Category.UNRESOLVED_FINDINGS, path=None, content="\n".join(unresolved)
            ),
        ],
    )
    request = registry.build_request(
        "verifier",
        prompt=load_role_prompt("verifier"),
        cwd=store.repo_root,
        context=packet,
    )
    result = invoke_structured(registry.adapter_for("verifier"), request, Verification)
    store.append_event(
        {
            "event": "verified",
            "outcome": str(result.outcome),
            "verdicts": [
                {"criterion": v.criterion, "verdict": v.verdict} for v in result.verdicts
            ],
        }
    )
    return result

# src/dev_orchestration/workflow/runner.py
"""Drive one run from a request to a local commit.

An escalation is a run *outcome*, not a crash: the caller gets a RunOutcome
naming the cause, and the manifest and event log say the same thing. A
traceback would lose the audit trail at exactly the moment it matters.
"""

import json
from pathlib import Path

from pydantic import BaseModel

from dev_orchestration.adapters.registry import RoleRegistry
from dev_orchestration.config.models import ProjectConfig
from dev_orchestration.context.assembler import ContextContractError
from dev_orchestration.domain.enums import RunState, Tier
from dev_orchestration.domain.findings import Verification
from dev_orchestration.git.repo import GitRepo
from dev_orchestration.scope import ScopeFence
from dev_orchestration.workflow.bootstrap import bootstrap_run
from dev_orchestration.workflow.engine import Engine
from dev_orchestration.workflow.invoke import SchemaEscalation
from dev_orchestration.workflow.scope_check import ScopeViolation, enforce_fence
from dev_orchestration.workflow.stages import (
    RemediationExhausted,
    classify,
    execute,
    plan,
    reconcile,
    review_implementation,
    review_plan,
    verify,
)
from dev_orchestration.workflow.validation import all_passed, run_validations


class RunOutcome(BaseModel):
    model_config = {"frozen": True}

    run_id: str
    final_state: RunState
    store_root: Path
    verification: Verification | None = None
    reason: str = ""


def _evidence(outcomes) -> str:
    return "\n".join(
        f"{o.name}: exit {o.exit_code} ({'pass' if o.passed else 'FAIL'})"
        for o in outcomes
    )


def execute_run(
    repo: GitRepo,
    project_config: ProjectConfig,
    registry: RoleRegistry,
    request_text: str,
    worktree_root: Path,
    acceptance_criteria: list[str],
) -> RunOutcome:
    # Classification happens before bootstrap because the tier decides whether
    # the clean-tree guard applies at all.
    probe_store, worktree = bootstrap_run(
        repo, project_config, request_text, Tier.STANDARD, worktree_root
    )
    engine = Engine(probe_store)
    fence = ScopeFence.from_config(project_config.scope)
    base_commit = probe_store.read_manifest().git.base_commit
    worktree_repo = GitRepo(worktree)

    try:
        classification = classify(
            registry, request_text, project_config.project.project_class, probe_store
        )
        engine.transition(RunState.CLASSIFIED)
        probe_store.update_manifest(tier=classification.tier)

        approved = ""
        if classification.tier is Tier.STANDARD:
            version = plan(registry, request_text, [], [], probe_store)
            engine.transition(RunState.PLANNED)
            review = review_plan(
                registry, request_text, version.read_text(), [], probe_store
            )
            engine.transition(RunState.PLAN_REVIEWED)
            if review.blocking_ids():
                version = reconcile(
                    registry, version.read_text(), review.findings, probe_store
                )
            probe_store.approve_plan(version)
            engine.transition(RunState.PLAN_FINALIZED)
            approved = probe_store.approved_plan()

        engine.transition(RunState.EXECUTING)
        execute(registry, approved, [], [], worktree, probe_store)

        engine.transition(RunState.VALIDATING)
        outcomes = run_validations(
            project_config.validation, classification.tier, worktree
        )
        probe_store.append_event(
            {"event": "validated", "passed": all_passed(outcomes)}
        )

        # Enforcement point 2: the diff, not the agent's account of it.
        enforce_fence(worktree_repo, base_commit, fence)

        engine.transition(RunState.IMPLEMENTATION_REVIEW)
        diff = worktree_repo.run_git("diff", base_commit, "HEAD")
        review = review_implementation(
            registry, approved, diff, _evidence(outcomes), [], probe_store
        )

        cycle = 1
        while review.blocking_ids():
            engine.transition(RunState.REMEDIATION)
            blocking = [f for f in review.findings if f.id in review.blocking_ids()]
            remediate_stage(
                registry, blocking, approved, diff, worktree, probe_store, cycle
            )
            engine.transition(RunState.VALIDATING)
            outcomes = run_validations(
                project_config.validation, classification.tier, worktree
            )
            probe_store.append_event(
                {"event": "validated", "passed": all_passed(outcomes)}
            )
            enforce_fence(worktree_repo, base_commit, fence)
            engine.transition(RunState.IMPLEMENTATION_REVIEW)
            diff = worktree_repo.run_git("diff", base_commit, "HEAD")
            review = review_implementation(
                registry, approved, diff, _evidence(outcomes), [], probe_store
            )
            cycle += 1

        engine.transition(RunState.FINAL_VERIFICATION)
        verification = verify(
            registry,
            request_text,
            approved,
            acceptance_criteria,
            diff,
            _evidence(outcomes),
            [f.id for f in review.findings],
            probe_store,
        )
        engine.transition(RunState.COMPLETE_LOCAL)
        return RunOutcome(
            run_id=probe_store.run_id,
            final_state=RunState.COMPLETE_LOCAL,
            store_root=probe_store.root,
            verification=verification,
        )

    except (
        RemediationExhausted,
        ScopeViolation,
        SchemaEscalation,
        ContextContractError,
    ) as exc:
        probe_store.append_event(
            {"event": "escalated", "cause": type(exc).__name__, "detail": str(exc)}
        )
        engine.transition(RunState.ESCALATED)
        return RunOutcome(
            run_id=probe_store.run_id,
            final_state=RunState.ESCALATED,
            store_root=probe_store.root,
            reason=str(exc),
        )
```

Import `remediate` as `remediate_stage` (or call it directly — the alias above exists only to keep the loop readable). The `json` import is unused in this listing; drop it if ruff flags it.

Note `bootstrap_run` is called with `Tier.STANDARD` before classification, which applies the clean-tree guard to *every* run. That is deliberate and stricter than the tier table: a dirty tree makes the diff-vs-fence check meaningless, and the check runs for trivial runs too. Record it as a ruling in your report rather than "fixing" it.

# src/dev_orchestration/workflow/reporting.py
"""Human-readable run status.

Never dumps the manifest. A user reading `status` wants to know what to do
next; handing them JSON makes them parse a data structure to find out.
"""

import json
from pathlib import Path

from dev_orchestration.domain.enums import RunState
from dev_orchestration.domain.run import RunManifest

# Every state carries guidance. A state with no next action leaves the user
# guessing, which is the problem this command exists to solve.
NEXT_ACTION: dict[RunState, str] = {
    RunState.CREATED: "run `dev-orch run` to start the loop",
    RunState.CLASSIFIED: "planning starts automatically for a standard run",
    RunState.PLANNED: "the plan is awaiting review",
    RunState.PLAN_REVIEWED: "reconciliation will address the review findings",
    RunState.PLAN_FINALIZED: "execution starts next",
    RunState.AWAITING_APPROVAL: "a human must approve the plan before execution",
    RunState.APPROVED: "execution starts next",
    RunState.EXECUTING: "the builder is working in the run worktree",
    RunState.VALIDATING: "configured validation commands are running",
    RunState.IMPLEMENTATION_REVIEW: "the diff is being reviewed against the plan",
    RunState.REMEDIATION: "blocking findings are being addressed",
    RunState.FINAL_VERIFICATION: "acceptance criteria are being judged",
    RunState.COMPLETE_LOCAL: (
        "review the branch and merge or push it yourself -- dev-orch never does"
    ),
    RunState.BLOCKED: "read the last event; the run needs a human decision",
    RunState.ESCALATED: "read the last event; the loop could not finish this safely",
    RunState.FAILED: "read the last event for the failure",
    RunState.CANCELLED: "the run was cancelled; start a new one if still needed",
}


def describe_status(manifest: RunManifest, events: list[dict]) -> str:
    lines = [
        f"Run:    {manifest.run_id}",
        f"Tier:   {manifest.tier}",
        f"Stage:  {manifest.status}",
    ]
    if manifest.git.branch:
        lines.append(f"Branch: {manifest.git.branch}")
    if events:
        last = events[-1]
        detail = last.get("detail") or last.get("outcome") or ""
        lines.append(f"Last:   {last.get('event', 'unknown')} {detail}".rstrip())
    lines.append(f"Next:   {NEXT_ACTION[manifest.status]}")
    return "\n".join(lines)


def read_events(store_root: Path) -> list[dict]:
    path = store_root / "events.jsonl"
    if not path.is_file():
        return []
    return [json.loads(line) for line in path.read_text(encoding="utf-8").splitlines()]


def list_runs(repo_root: Path) -> list[tuple[str, str]]:
    """Run ids and their states, newest first.

    Run ids lead with a UTC timestamp, so reverse lexical order is reverse
    chronological order.
    """
    runs_dir = repo_root / ".ai" / "runs"
    if not runs_dir.is_dir():
        return []
    listed = []
    for directory in sorted(runs_dir.iterdir(), reverse=True):
        manifest_path = directory / "manifest.json"
        if not manifest_path.is_file():
            continue
        manifest = RunManifest.model_validate_json(manifest_path.read_text())
        listed.append((manifest.run_id, str(manifest.status)))
    return listed
```
